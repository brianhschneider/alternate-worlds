# Alternate Worlds

Policies for the software that publishes [Alternate Worlds](https://bschneidmtg.substack.com)
podcast clips to social media.

- [Privacy Policy](privacy/index.md)
- [Terms of Service](terms/index.md)

Published at <https://brianhschneider.github.io/alternate-worlds/>.

Kept here, in version control, so that a change to what the publishing software does shows up
as a change needed in these documents. An earlier draft claimed the software stored no
third-party personal data while it in fact held 99 guests' names and social handles — that
gap existed because the policy lived somewhere the code did not.

Operated by Brian Schneider. Alternate Worlds is a personal project, not a Funfab property.
