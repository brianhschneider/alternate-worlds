# Alternate Worlds

A podcast about making *Magic: the Gathering* and about game making, by Brian Schneider.

**The show:** [bschneidmtg.substack.com](https://bschneidmtg.substack.com)

---

## Publishing software

This repository holds the policies for the software that publishes Alternate Worlds clips to
social media — TikTok ([@alternateworldsmtg](https://www.tiktok.com/@alternateworldsmtg)),
YouTube, Instagram, Threads and Bluesky.

- **[Privacy Policy](privacy/)** — what the software collects (nothing, from viewers) and what
  is held about podcast guests
- **[Terms of Service](terms/)**

These live in version control next to the code they describe, so that a change to what the
software does shows up as a change needed here.

*Operated by Brian Schneider. Alternate Worlds is a personal project and is not a Funfab
property.*
